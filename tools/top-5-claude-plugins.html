5 free Claude plugins that replace apps you pay for

The five Claude Code plugins climbing GitHub this month, what each one does for you, and the exact command to install it.

★ 21.4K stars combinedAll MIT licensedOne command each

Screenshots: each project's GitHub page. Agentic Insider is not affiliated with these projects.

By the Agentic Insider desk · Oct 28, 2026 · Sources: Jakeschincariol/replica-skill

5. tstack

Your code change goes all the way to a merged pull request, with nobody watching. The agent skills Theo uses every day, for Claude Code and Codex.

★ 2,247 on GitHub · MIT · github.com/t3dotgg/tstack
git clone https://github.com/t3dotgg/tstack
# then copy its skills folder into ~/.claude/skills/

4. OpenFilm

Ask for a launch video and watch your agent edit it. Turns any coding agent into a video agent, with an editor to change anything it makes.

★ 3,359 on GitHub · MIT · github.com/openfilm/openfilm
npx skills add openfilm/openfilm

3. Answer me with HTML

Ask a hard question, get a one-page visual answer instead of a wall of text. The agent answers in a single HTML page you can actually read and share.

★ 4,591 on GitHub · MIT · github.com/QingYunA/answer-me-with-html
/plugin marketplace add QingYunA/answer-me-with-html
/plugin install answer-me-with-html@answer-me-with-html

2. Logo Design

Describe your brand, get real SVG logo files you can use today. Principles, process, SVG craft and testing tools, with a reference library of 1,400+ logos.

★ 4,970 on GitHub · MIT · github.com/kaankiziltug/logo-design-skill
/plugin marketplace add kaankiziltug/logo-design-skill
/plugin install logo-design@logo-design-skill

1. Replica

Rebuilds any app, reads what its users hate, and fixes it, so you have something to sell. Eleven skills: reverse-engineer an app, rebuild it, test it for bugs, then fix what its reviews complain about.

★ 6,263 on GitHub · MIT · github.com/Jakeschincariol/replica-skill
/plugin marketplace add Jakeschincariol/replica-skill
/plugin install replica-skill@replica-skill
