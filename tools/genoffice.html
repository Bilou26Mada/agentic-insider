GenOffice: a free, open-source Office suite with an AI agent in every document

It opens and saves real .docx, .xlsx and .pptx files, and the AI edits the file itself, showing every change as tracked changes you can undo.

★ 10.8K on GitHubApache 2.0Free

Why it matters

  • Runs on Mac, Windows and Linux
  • PDF to Word, Excel or PowerPoint conversion on your own computer
  • Bring your own key for Claude, ChatGPT, Gemini, DeepSeek or a local model

How to try it

  1. Download the installer for your system from the latest release.
  2. Open any Word, Excel or PowerPoint file.
  3. Ask the AI for a change and review it as tracked changes.
  4. Star a folder of documents and ask questions across them, with the source file for every answer.
