Home / Tools / ARTEMIS

Google's open-source AI uses an Android phone like a human

You type a task in plain English. ARTEMIS reads the screen, taps, types and swipes on a real Android phone until the job is done.

Why it matters

  • About 3 to 5 seconds per step
  • Over 99% of tasks finished on Google Research's AndroidWorld benchmark (100+ multi-step tasks)
  • Connects to Claude Code, Cursor, Codex and Windsurf through MCP

How to try it

  1. Plug in an Android phone with USB debugging on, or start an emulator.
  2. Clone the repo and run ./start.sh (Mac/Linux) or start.bat (Windows).
  3. Let the script install what it needs: ADB, scrcpy, FFmpeg and Python.
  4. Describe the task in plain English and watch the phone do it.
