30 open-source MCP servers

MCP lets an AI agent use your apps through small servers. Here are 30 open-source ones, from the official basics to GitHub, Playwright, Notion, Supabase, Stripe and Cloudflare. Each link goes to the publisher's own repository.

How we picked them

  • Every repository was checked on GitHub on November 6, 2026: it exists, has an open-source licence and is not archived
  • All of them had code pushed in the weeks before we checked
  • Most are published by the company behind the app (GitHub, Microsoft, Notion, Stripe, Cloudflare, AWS...); the first five come from the MCP project itself
  • Open source means the code is free; some services still need an account or an API key
  • A server can do whatever its tools allow, so read every approval pop-up and give it the smallest access it needs

The 30 servers

  1. Filesystem (the basics): Read and edit files in folders you allow. github.com/modelcontextprotocol/servers
  2. Fetch (the basics): Turn any web page into clean text. github.com/modelcontextprotocol/servers
  3. Git (the basics): Read, search and commit in your repos. github.com/modelcontextprotocol/servers
  4. Memory (the basics): A knowledge graph your AI keeps between chats. github.com/modelcontextprotocol/servers
  5. Sequential Thinking (the basics): Step-by-step reasoning for hard problems. github.com/modelcontextprotocol/servers
  6. GitHub (code): Issues, pull requests and code from the chat. github.com/github/github-mcp-server
  7. Playwright (code): Your AI drives a real browser. github.com/microsoft/playwright-mcp
  8. Chrome DevTools (code): Debug and profile live web pages. github.com/ChromeDevTools/chrome-devtools-mcp
  9. Context7 (code): Up-to-date library docs, no outdated code. github.com/upstash/context7
  10. Docker MCP Gateway (code): Run your MCP servers safely in containers. github.com/docker/mcp-gateway
  11. Brave Search (search the web): Private web, news and image search. github.com/brave/brave-search-mcp-server
  12. Exa (search the web): Web search and crawling built for AI. github.com/exa-labs/exa-mcp-server
  13. Firecrawl (search the web): Scrape any site into clean markdown. github.com/firecrawl/firecrawl-mcp-server
  14. Tavily (search the web): Real-time search, extract and crawl. github.com/tavily-ai/tavily-mcp
  15. Apify (search the web): Ready-made scrapers for social media, maps and shops. github.com/apify/apify-mcp-server
  16. Supabase (databases): Query and manage your Supabase project. github.com/supabase/mcp
  17. MongoDB (databases): Talk to your MongoDB data in plain English. github.com/mongodb-js/mongodb-mcp-server
  18. Neon (databases): Serverless Postgres: create, branch, query. github.com/neondatabase/mcp-server-neon
  19. Redis (databases): Read and write your Redis data. github.com/redis/mcp-redis
  20. MCP Toolbox for Databases (databases): BigQuery, Postgres, MySQL and more, by Google. github.com/googleapis/mcp-toolbox
  21. Notion (work apps): Search, read and write your Notion pages. github.com/makenotion/notion-mcp-server
  22. Atlassian (work apps): Jira tickets and Confluence pages. github.com/atlassian/atlassian-mcp-server
  23. Stripe (work apps): Payments, customers and invoices from the chat. github.com/stripe/ai
  24. MarkItDown (work apps): PDF, Word and Excel into text your AI reads. github.com/microsoft/markitdown
  25. Netlify (work apps): Build and deploy websites from a prompt. github.com/netlify/netlify-mcp
  26. Cloudflare (cloud & ops): Workers, DNS, logs and more. github.com/cloudflare/mcp-server-cloudflare
  27. AWS (cloud & ops): Official servers for AWS services and docs. github.com/awslabs/mcp
  28. Grafana (cloud & ops): Dashboards, alerts and logs in plain English. github.com/grafana/mcp-grafana
  29. Terraform (cloud & ops): Write infrastructure code with live provider docs. github.com/hashicorp/terraform-mcp-server
  30. Browser MCP (cloud & ops): Automate the Chrome you are already logged into. github.com/BrowserMCP/mcp
