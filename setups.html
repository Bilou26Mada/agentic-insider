02

The Claude Code bug-fixing setup (4 MCP servers)

GitHub MCP reads the bug report, Context7 brings today's docs, Chrome DevTools MCP sees the console errors, Playwright MCP clicks through and tests the fix.

#1 GitHub MCP
claude mcp add --transport http github https://api.githubcopilot.com/mcp -H "Authorization: Bearer YOUR_GITHUB_PAT"
#2 Context7
npx ctx7 setup --claude
#3 Chrome DevTools MCP (inside Claude Code)
/plugin marketplace add ChromeDevTools/chrome-devtools-mcp
/plugin install chrome-devtools-mcp@chrome-devtools-plugins
#4 Playwright MCP
claude mcp add playwright npx @playwright/mcp@latest
